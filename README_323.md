# Home Sweet Home 3.2.3 — Five-Dinner Weekly Planner

Upload `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, and `icon.svg` from this folder to the ROOT of the preview repository.

Open preview with `?test=323`. In Meals > 5-Dinner Planner, choose a recipe for Monday–Friday. A combined ingredient list removes duplicate ingredient names. Tap Add all to Groceries to merge without duplicating existing entries, or Copy list for AnyList. The original meal planner and separate Household list are preserved. Recipes do not include measured quantities, so ingredient consolidation is by ingredient name rather than summing amounts. Week selections save locally, including in app backup exports.

Do not clear Safari website data or replace the live repository before testing.
