# Home Sweet Home 3.2 — The Little Cottage Edition

Upload the **contents of this folder** to the **home-sweet-home-preview** GitHub repository root. Do not replace the live repository until you test.

## Added
- Mama’s Helping Hand: four energy levels and realistic evening suggestions
- Mama Brain Dump: capture and manually sort reminders into grocery or household lists
- Two independent AnyList copy lists: groceries and household essentials
- Family Recipe Box: eight built-in recipes, filters, favorites, ingredient handoff, toddler serving notes
- Bailey’s Little World: activity ideas and daily daycare bag checklist
- Gratitude Garden: flowers grow with saved gratitudes and answered prayers
- Updated version label and service worker network-first navigation to reduce stale pages

## Preserved
Existing localStorage key and data; Morning Grace Cloudflare NLT integration; original meal planner, groceries, routines, laundry, calendar, prayers, memories, Survival Mode, Tomorrow Me, maintenance and backups.

## Important
This is a preview build. App data is saved separately per GitHub Pages site/browser, not synchronized between live and preview. Export a backup from More before testing imports or making major changes. Do not delete the old app or clear Safari website data.

Recipe ideas are locally curated, not live internet search. AnyList is a manual clipboard handoff. Brain Dump routing is manual, not AI. No push notifications.
